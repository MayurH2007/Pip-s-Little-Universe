## About the Project

Welcome to the Midnight Nursery, a dreamy little corner of the internet where Pip, a sleepy baby and Junior Dream Engineer, creates magical dreams to help everyone drift peacefully into sleep.

**Pip's Little Universe** is a creative web experience built for the **Baby's First Website Hackathon by haX.baby**. Inspired by bedtime stories, glowing stars, and cozy nights, the project transforms a simple website into an interactive little world.

Our goal is to combine playful storytelling, thoughtful design, animations, and interactive elements to create an experience that feels magical from the moment you enter.

## Features

- **Meet Pip:** Get to know our tiny Junior Dream Engineer.
- **Lullaby Lab:** Explore a music-box-inspired experience with soothing sounds.
- **Nightlight Collection:** Discover a collection of dreamy lights.
- **Dream Delivery:** Follow the journey of dreams across a sleepy village.
- **Pip's Story:** Discover the story behind Pip and the Midnight Nursery.
- **Little Surprises:** Find playful interactions and hidden Easter eggs.

## Design Philosophy

We want every corner of Pip's universe to feel like a page from a bedtime story.

- Soft, dreamy colors and glowing visual elements
- A cozy night-sky atmosphere
- Playful animations and interactive details
- Storytelling that makes the experience feel personal
- A simple, welcoming interface that's fun to explore

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/arshitaaa-12/Pip-s-Little-Universe.git
```

**2. Navigate to the project directory**

```bash
cd Pip-s-Little-Universe
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the project.
