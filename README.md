# 🌙 Pip's Little Universe

Hey everyone! 👋

Welcome to Pip's Little Universe! ✨

So basically, this is our project for the **Baby's First Website Hackathon by haX.baby**. We're building a cute, dreamy little world around Pip, a sleepy baby who works as a Junior Dream Engineer at the Midnight Nursery. 🍼🌟

Pip's job is to create dreams, lullabies, and nightlights to help everyone sleep peacefully. And honestly, we thought it would be really cool to turn that idea into a website!

## 🌌 What's this website about?

Imagine a little observatory floating in the night sky, surrounded by stars, glowing lanterns, and sleepy clouds. That's the kind of world we're trying to create!

Here's what we're planning to include:

- 🌙 **Meet Pip** — Get to know our little dream engineer.
- 🎵 **Lullaby Lab** — A tiny music box with soothing sounds.
- 🏮 **Nightlight Collection** — Explore cute little lights that brighten up the night.
- ⭐ **Dream Delivery** — Follow Pip's journey as dreams are delivered across a sleepy village.
- 📖 **Pip's Story** — Discover how Pip became a dream engineer.
- ✨ **Little Surprises** — Some interactive elements and a secret Easter egg for curious visitors!

## 🎨 Our vibe

We want the website to feel like stepping into a bedtime story, with warm colours, cute illustrations, glowing stars, and little animations.

Think cozy nights, dreamy skies, and a little bit of internet nostalgia. 💗

## 🛠️ Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Framer Motion
- Web Audio API

We wanted to create something different from a normal portfolio website.

Something playful, interactive, and full of little details that make people smile.
